# Compressor | Abu Al-Dahab Management

A professional website providing sewage, drainage, and waste management services across Saudi Arabia.

## Services

- Septic Tank Treatment
- Drainage and Sewer Unblocking
- Frozen Grease Removal
- Water Tank Cleaning
- Industrial Waste Removal
- Sewage and Wastewater Services

## Technologies

- React
- Vite
- JavaScript
- CSS

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd compressor-site
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
